# **Help & Support**

If you are using Ember Link, a star on the project's [GitHub repository](https://github.com/ElijahJohnson5/Ember-Link) is the easiest way to show your support. For questions and conversations, the project's [Discord](https://discord.gg/YU2wGQtgE7) is the fastest place to get a response.

## **Bug Reporting**

Bug reports are tracked as issues on [GitHub](https://github.com/ElijahJohnson5/Ember-Link/issues). Please include the SDK version, the server target (Docker or Cloudflare Workers), and a minimal reproduction whenever possible.

If you would like a fix sooner, contributions are always welcome. Pull requests are reviewed regularly.

## **Community Support**

- **Discord.** Ask questions, share ideas, and connect with other Ember Link developers on the [Discord server](https://discord.gg/YU2wGQtgE7).
- **GitHub Discussions.** Longer-form troubleshooting, feature requests, and design discussions live in [GitHub Discussions](https://github.com/ElijahJohnson5/Ember-Link/discussions).
